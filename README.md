# Proyecto-DWEC

## Backlog

- Inicialmente 2 roles: Monitor y alumno ( podría valorar incluir profesor a futuro)
- Registro/Inicio sesión via credenciales iPasen/iSéneca

### Backlog -- Alumno

- El alumno podrá ver a los monitores del centro, con foto y nombre, detallando además si están en el centro y acceso al horario del mismo monitor
- El alumno podrá solicitar asistencia a los monitores, siguiendo una serie de casos generales definidos (Ir al baño, Ayuda con ropa, Ayuda en desplazamiento...) y podrá añadir una observación libre. Dicha solicitud será notificada a los monitores que estén en el centro.

### Backlog -- Monitor

- El monitor deberá hacer un check-in diario para indicar que está en el centro, a partir de ese momento se marcará su asistencia y podrá recibir notificaciones, al salir del centro, el mismo botón hará un checkout.
